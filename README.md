# RunLog

ランニング・散歩の記録（距離・時間・メモ）を登録すると、その日の天気を
[OpenWeatherMap API](https://openweathermap.org/current) から自動で取得して一緒に保存する Web アプリです。

## 主な機能

| 機能 | 内容 |
|---|---|
| アカウント | ユーザー登録（登録後は自動ログイン）、ログイン、ログアウト |
| 記録の管理 | 記録の登録・一覧・詳細・編集・削除。**自分の記録だけ**が表示・操作できます |
| 天気の自動取得 | 今日の日付で記録すると、その日の天気（天気・気温・湿度・風速）を自動で取得して一緒に保存します |
| 月のサマリー | 一覧の上部に、今月の合計距離・回数・合計時間・平均ペースと、日ごとの距離・天気の棒グラフを表示します |
| ペースの表示 | 一覧と詳細に、1km あたりのペース（例: 6'40"/km）を表示します |
| プロフィール | 「よく走る都市」を設定すると、新規登録の都市欄の初期値になります |

## 技術スタック
Python 3.12 / Django 5.x / MySQL 8.0 / Bootstrap 5 / Docker Compose

## セットアップ

**最初に環境変数ファイル（.env）を作成します**
- Mac、Windows(PowerShell、Git Bash)の場合
```.sh
cp .env.example .env
```
- Windows(コマンドプロンプト)の場合
```
copy .env.example .env
```

`.env` を開いて、以下の値を書き換えてください。

| 変数 | 内容 |
|---|---|
| `SECRET_KEY` | Django の秘密鍵。推測されにくい長いランダム文字列にする |
| `MYSQL_PASSWORD` / `MYSQL_ROOT_PASSWORD` | MySQL のパスワード |
| `OPENWEATHER_API_KEY` | OpenWeatherMap の API キー（無料プランで可）。空でもアプリは動くが、天気は取得されない |

※ `.env` は秘密情報を含むため、Git にコミットしないでください（`.gitignore` 済み）。

## 起動方法
1. イメージのビルド

```.sh
docker compose build
```
- `docker-compose.yml` の内容に従って、コンテナイメージをビルドします。
- 初回または依存パッケージを更新したときに実行してください。

2. コンテナの起動

```.sh
docker compose up
```
- コンテナを起動します。MySQL の起動を待ってから Django が立ち上がります。
- `-d` オプションをつけるとバックグラウンドで起動します。

3. データベースの初期化（初回のみ）

別のターミナルで実行します。

```.sh
docker compose exec web python manage.py migrate
```

停止したいときは `Ctrl + C` または以下のコマンドを使ってください：
```.sh
docker compose down
```
- DB のデータは `mysql_data` ボリュームに残ります。データも消す場合のみ `docker compose down -v` を使います。

**ブラウザで確認**
```
http://localhost:8000
```

「アカウントを作成」から登録し、「記録する」で今日の日付の記録を作ると、天気が一緒に保存されます。

### 管理画面（任意）
```.sh
docker compose exec web python manage.py createsuperuser
```
作成後、http://localhost:8000/admin/ にログインできます。

## 使い方

1. **アカウントを作成する**
   トップページの「アカウントを作成」から、ユーザー名とパスワードを登録します。登録すると自動でログインされ、記録一覧が開きます。
2. **よく走る都市を設定する（任意）**
   ヘッダーの「プロフィール」で、都市名を英語で保存します（例: `Tokyo`）。以降の新規登録で、都市欄に自動で入ります。
3. **記録をつける**
   「記録する」を押して、下の表の内容を入力します。保存すると詳細画面が開きます。
4. **天気を確認する**
   日付が**今日**の記録には、詳細画面に天気（天気・気温・湿度・風速・取得した日時）が表示されます。
5. **一覧で振り返る**
   記録一覧で、今月の合計とグラフ、記録の行（日付・種別・距離・天気・時間・ペース）を確認できます。行を押すと詳細が開きます。
6. **編集・削除する**
   詳細画面の「編集する」で内容を直せます（天気は取得し直しません）。「削除する」を押すと確認画面が開き、そこで削除すると元に戻せません。

### 入力する項目

| 項目 | 入力のルール |
|---|---|
| 種別 | ランニング / 散歩 |
| 日付 | 未来の日付は入力できません。初期値は今日です |
| 距離 | 0 より大きく 100 km 以下（小数 2 桁まで） |
| 時間 | 1 分以上 1440 分以下 |
| 都市 | 必須。**英語の都市名**で入力します（例: `Tokyo`、`Osaka`）。同名の都市がある場合は `Kyoto,JP` のように国コードを付けます |
| メモ | 任意。1000 文字以内 |

入力が間違っているときは、項目の下に理由が表示されます。

### 天気の表示の見方
- 天気は、**晴れ（黄土色）・くもり（青緑）・雨（青）** の 3 つにまとめて表示します。雪・雷雨は「雨」、霧・靄などは「くもり」に含まれます。
- 一覧の記録の行は、左端の縦線がその日の天気の色です。天気がない記録は、色の代わりに点線で表示されます。
- 月のサマリーの棒グラフは、**棒の高さが距離、色が天気**です。棒にマウスを乗せると、日付・距離・天気が表示されます。
- 天気がない記録は、過去の日付で登録した場合や、天気を取得できなかった場合です。記録そのものは保存されます。

## 画面一覧
| 画面 | URL | ログイン |
|---|---|---|
| トップ | `/` | 不要 |
| ユーザー登録 | `/signup/` | 不要 |
| ログイン | `/login/` | 不要 |
| 記録一覧 | `/records/` | 必要 |
| 記録詳細 | `/records/<id>/` | 必要 |
| 新規登録 | `/records/new/` | 必要 |
| 編集 | `/records/<id>/edit/` | 必要 |
| 削除確認 | `/records/<id>/delete/` | 必要 |
| プロフィール | `/profile/` | 必要 |

## 天気取得の仕様
- 天気を取得するのは**新規登録時で、日付が今日の場合のみ**です（無料プランは現在の天気しか取れないため）。過去日付の記録は天気なしで保存されます。
- 編集時は天気を再取得しません（記録した時点の天気を残します）。
- 都市名は英語で入力します（例: `Tokyo`, `Osaka`）。
- API のエラーやタイムアウト、API キー未設定の場合でも、記録は保存され「天気を取得できませんでした」と表示されます。
